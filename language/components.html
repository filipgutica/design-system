Components

Every component in the design language, in each state that applies. The styles use only tokens.css, and the markup carries the roles and states a React or Vue version should copy. Component specs describe each one; decisions say why.

Each component’s badge names its layer: a new project adopts Core as it is, with its own hue and fonts set in the tokens.css identity block, and replaces Identity with its own look. The first specimen in each row is live. The others pin one state for display and do not respond, and every caption names its state.

By purpose

Actions

  • ButtonThe main action control: primary, secondary, ghost, danger, and text.
  • Quiet actionA small transparent action inside a component, such as Copy or Close.

Selection

  • Checkbox and radioPick several options, or one from a short list.
  • Radio card groupPick one option that needs a description.
  • SwitchTurn a setting on or off at once.
  • Toggle buttonA labelled card that latches on, with a switch inside.
  • Segmented controlTwo to five short options that apply at once.

Inputs

  • Text input and textareaType a short value or a longer note.
  • SelectChoose from a longer list.
  • Field wrapperLabel, description, and error text around a field.
  • SliderSet a value in a range.

Feedback and status

  • ProgressShow how far a task has got.
  • ScoreShow a value out of a maximum.
  • BadgeA short status label.
  • AlertA real caveat or status message in the page.

Containers and overlays

  • Surface and cardPanels and cards for parallel, comparable content.
  • FigureAn image or diagram with a caption.
  • DialogA modal task that needs an answer before the page continues.
  • DrawerA side panel, such as phone navigation.

Navigation

  • Navigation listRows of links with current page and current location.
  • Section railA sticky list of sections that moves into a drawer on phones.
  • Find fieldFilter a navigation list as you type.
  • BreadcrumbsThe path from the site to this page.
  • PagerPrevious and next pages in a sequence.
  • TabsSwitch panels about one object, without leaving the page.
  • Skip linkJump past the header to the content.
  • Keyboard keyShow a key or shortcut in text.

Code and examples

  • Code blockSource code with an optional header and Copy, and a live example above it.

Identity: terminal folio

  • Command plateA shell command on a hue-tinted plate.
  • Terminal captureA recorded terminal screen with a status line.
  • Site headerThe ~/name header with project switcher and appearance.
  • Page type and helpersMono headings, steps, definitions, facts, and the footer.
