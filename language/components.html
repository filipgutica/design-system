Components

Every component in the design language, in each state that applies. The styles use only tokens.css, and the markup carries the roles and states a React or Vue version should copy. Component specs describe each one; decisions say why.

Each component’s badge names its layer: a new project adopts Core as it is, with its own hue and fonts set in the tokens.css identity block, and replaces Identity with its own look. The first specimen in each row is live. The others pin one state for display and do not respond, and every caption names its state.

Actions

Start, confirm, or cancel something.

Button

CoreSpec

The main action control: primary, secondary, ghost, danger, and text.

Do
One primary button in each decision group, labelled with a verb for its result, such as “Save changes”. Every other action in the group is secondary, ghost, or text. Give a lone icon a circle when it is the one icon action in its group that needs a fill, such as Send or Update, and put it at the end of its row.
Don’t
The danger variant on an action the reader can undo. Danger marks an action that destroys something. An icon-only ghost or text button: a lone icon with no fill at rest is a quiet action, because the two look the same at rest and would hover in different shapes.

Quiet action

CoreSpec

A small transparent action inside a component, such as Copy or Close.

Do
Use it for an action inside a component: Copy in a code block or command list, close in a dialog or drawer, Full size on a capture, the project trigger, and the overflow menu trigger. Use it too for any icon-only action that needs no fill at rest, such as the utilities in a sidebar footer or Help at the end of an action bar. In a row of controls it is a square at that row’s control size, and it grows to --control-touch at tablet width.
Don’t
A labelled action that stands on its own in the page, such as Save or Next. That is a button. A lone icon that needs a fill at rest, such as Send: that is an icon-only button, a circle.

One recipe for Copy, Full size, dialog and drawer close, the project trigger, and the overflow menu trigger. Each component sets only its size and place.

Overflow menu

CoreSpec

Two or more secondary actions behind a More button.

Do
Use it for two or more secondary actions of a row, card, or toolbar, ordered by how often they are used. Put a destructive action last, after a separator, and confirm it in a dialog.
Don’t
The item’s primary action, a recovery action such as Retry on a failed item, a menu with one action, or links to other pages. Those stay buttons or links.

The trigger is a quiet action, and the menu is a floating layer with concentric rows. The live trigger follows the menu button pattern: arrows, Home, End, a first letter, Escape, and Tab.

CoreSpec

Two to five short options that apply at once.

Do

Do

Don’t

Alert

CoreSpec

A real caveat or status message in the page.

Do
Use an alert for a caveat or status message the reader needs before acting. When action is needed, name it, such as “Reconnect the source to resume sync”.
Don’t
An alert for decoration or routine emphasis. A short status label is a badge; explanations and recovery instructions stay in an alert. An alert that repeats the summary sentence, a badge, or the heading in view, or a second alert in the same view.

Mono, or a mark such as ##, on a heading.
