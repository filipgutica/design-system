# Design system

The design language lives in this plugin's `language/` folder, at
`../../language/` from this skill's base directory. Resolve that path, then
read `../../language/DESIGN.md` first and follow it. It sets precedence, picks
the format, and names the other files in that folder to read, such as
`components.md`, `components.html`, `decisions.md`, `visualizations.md`, and
`tokens.css`.
